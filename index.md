## How to Use This Study Guide

1. **Sequential Study** - Read through the books in order to understand the biblical narrative
2. **Topical Study** - Use the [Thematic Index](indexes/thematic-index/) to explore themes across multiple books
3. **Book Study** - Deep dive into individual books with overviews and themes as your foundation
4. **Devotional Reading** - Use practical applications for daily reflection and spiritual growth
5. **Teaching Prep** - Use quick reference tables and summaries for lesson planning

## Quick Start

### New to Bible Study?
Start here:
1. Read the [Gospels](new-testament/01-matthew/) (Matthew, Mark, Luke, John) to learn about Jesus
2. Read [Acts](new-testament/05-acts/) to see the early church
3. Read [Genesis](old-testament/01-genesis/) to understand beginnings
4. Explore [Psalms](old-testament/19-psalms/) for worship and prayer

### Looking for Something Specific?
- **Press `/`** to search for any book or topic
- Browse the **[Thematic Index](indexes/thematic-index/)** for topics like faith, grace, prayer, or justice
- Check the **[Character Index](indexes/character-index/)** to study biblical figures
- View the **[Timeline](timeline/)** to understand chronological context

### Want to Go Deeper?
- Each book includes **recommended commentaries** for further study
- Use the **[Maps & Geography](resources/maps/)** to visualize biblical locations
- Print study sheets using the **[Printing Guide](resources/printing-guide/)**
